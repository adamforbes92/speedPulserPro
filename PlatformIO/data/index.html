Closed-Loop Feedback (PID)

When enabled, the motor's own tacho pulse is compared to the requested speed and the PWM duty is trimmed so the motor tracks the target.

Below this target the loop runs open-loop (feed-forward only) to stop low-speed hunting. Set to 0 to always run closed-loop.

Within this many Hz of target the P/D terms are silenced to stop needle hunting; the integral still trims out the last error. Lower = tighter tracking, higher = calmer needle. 0 = always full PID.

Motor Voltage Control

The motor is driven with one drive value (rail volts × PWM). Above 3.0 V × Nominal PWM the PWM stays at Nominal and only the rail moves, which keeps low speeds smooth. Below that the rail stays at its 3.0 V minimum and the PWM falls to zero, so the drive reaches all the way down to a stopped needle. Running speeds come from the marks captured on the Calibration page. Untick to fall back to the fixed 9 V rail and the legacy PWM presets.

Changing these settings after calibrating moves the needle: recapture the marks.

Feedback trim (only with Feedback Enable on, a working tacho, and above Min Feedback Speed): one slow loop nudges the calibrated drive to hold the motor speed captured for each mark. It does nothing inside the PID Deadband and can never move the drive more than the limit below, so it can't fight the calibration. The PID Kp/Ki/Kd sliders are for legacy boards only.

Speed Selection

Replaces the old pull-up / pull-down jumper on the Speed input. Open-collector hall sensors need the 12 V pull-up; push-pull sources such as Can2Cluster or a sensor with its own resistor work with None. Only one of the two is ever switched in.

Drive Calibration

  1. Run Test Board on the Diagnostics page once (--).
  2. Tick Calibration Mode. The motor starts stopped.
  3. Raise the Drive until the needle sits exactly on a mark, wait for Steady, enter the mark and press Capture Mark.
  4. Capture a low mark (e.g. 20), the top mark, and a few in between. Running speeds are interpolated between the marks, so more marks means a closer needle.

Export / Import

There are two kinds of calibration, and each file says which it is on its "type" line:

  • Voltage cal (speedpulser-voltage-cal): the Drive Calibration marks, each a needle speed against a drive in volts (rail × PWM), plus the Nominal PWM and Maximum Rail they were captured with. Used on a voltage board with Voltage Control on.
  • PWM cal (speedpulser-pwm-cal): the Calibration Builder points, each a needle speed against a motor PWM duty on the fixed ~9 V supply. Used on legacy boards, or with Voltage Control off.

Import Text opens a .txt file, shows it here, and loads it as whichever kind it is.

Export PWM C-Array saves a paste-ready firmware preset (a motorPerformanceN[] table plus its calibrationProfiles[] line) for building it in as a permanent PWM calibration.

Test Board stops the motor for a few seconds, steps the motor rail to 5, 7.5 and 10 V, and reads each one back on V_MOT_SENSE. A pass proves the voltage-injection path and the rail sense, and stores this board's own voltage line. Run it once on a new board, on a 12 V+ supply.
