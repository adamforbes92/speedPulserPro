Closed-Loop Feedback (PID)

When enabled, the motor's own tacho pulse is compared to the requested speed and the PWM duty is trimmed so the motor tracks the target.

Below this target the loop runs open-loop (feed-forward only) to stop low-speed hunting. Set to 0 to always run closed-loop.

Within this many Hz of target the P/D terms are silenced to stop needle hunting; the integral still trims out the last error. Lower = tighter tracking, higher = calmer needle. 0 = always full PID.
